🎮 2. How to Use the App (Step-by-Step)

1. Open the Clubhouse Door (Login)

Go to http://localhost:5173. Enter your username and password, or click the quick demo buttons to auto-fill them!

2. Look at the Scoreboard (Dashboard)

See big counters for all 20 devices. Check out the "Action Required" list for gadgets that have a boo-boo (Faulty or In Repair) so they can be fixed fast.

3. Search the Big Toy Chest (Devices Directory)

Click Devices in the sidebar. Type any name, room, or sticker tag into the search bar. Click Export CSV to save a clean spreadsheet file!

4. Add a Brand New Toy (+ Add Device)

Fill out the gadget name, brand, model, and give it an Asset Tag (like BPE-ICT-001). Asset tags are unique name badges — no two gadgets can have the same tag!

5. Move or Fix a Device & The Little Detective (History Log)

If someone moves a laptop from Room 101 to Room 205, click Edit and update the room. The system automatically records: Who moved it, what was changed, and what time it happened!

🧱 3. How Was It Coded? (The 3 Best Friends)

The code is split into three friendly helpers working together:

[ 1. Frontend: React + Vite ] --> The pretty Face & Buttons you see on screen
                                        │ (Sends your clicks with a secure JWT badge)
                                        ▼
[ 2. Backend: Express.js (Node) ] --> The Postman who enforces security rules
                                        │ (Writes and reads rows safely)
                                        ▼
[ 3. Database: SQLite (devices.db) ] --> The Big Memory Notebook that never forgets
Component Tool Used What It Does In Plain Words
Frontend React + Vite Draws the cards, charts, and forms without reloading the browser.
Backend Node.js + Express Checks who is logged in, validates inputs, and guards sensitive actions like deleting.
Database better-sqlite3 Stores your devices, login passwords (scrambled with bcrypt), and history logs in a local file.
